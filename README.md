# Intra-Paper Claim Verification

Repository structure for reproducibility artifacts.

Pipeline
1. Extract Introduction and Methods
2. Extract Novelty Claims
3. Extract Claim-Relevant Method Evidence
4. Generate Claim Verification Reviews
5. Extract Human Review Categories
6. Generate Review Summaries

Artifacts
- Prompts
- Evaluation Rubrics
- Reviewer Instructions
- Analysis Scripts
- Paper Identifiers
- Sample Outputs
